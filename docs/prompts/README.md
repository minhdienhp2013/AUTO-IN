# Prompt AI V1

Repo: https://github.com/minhdienhp2013/AUTO-IN.

Gửi AI đúng prompt bên dưới. Các prompt đều yêu cầu đọc quy tắc chung trong repo; không cần dán lại đặc tả mỗi lượt. AI0 là cuộc trò chuyện điều phối hiện tại; AI1–AI5 là các vai trò riêng, chưa được tự khởi chạy bởi bộ tài liệu này.

| AI0 — Điều phối | [AI0_DIEU_PHOI.md](AI0_DIEU_PHOI.md) |
| AI1 — Nghiệp vụ | [AI1_NGHIEP_VU.md](AI1_NGHIEP_VU.md) |
| AI2 — Zalo/hội thoại | [AI2_ZALO_HOI_THOAI.md](AI2_ZALO_HOI_THOAI.md) |
| AI3 — Tài liệu/máy in | [AI3_TAI_LIEU_MAY_IN.md](AI3_TAI_LIEU_MAY_IN.md) |

| AI5 — Kiểm thử | [AI5_KIEM_THU.md](AI5_KIEM_THU.md) |

Các lượt tiếp theo gửi ngắn:

AI nhận: AIx
Việc: V1-xxx — đầu ra cần đạt
BASE SHA: SHA thực đã kiểm tra
File được sửa: đường dẫn chính xác
Phụ thuộc: hợp đồng/commit hoặc không
Đạt khi: ca thử + kết quả cần có

Đọc [bảng phân công](../PHAN_CONG_AI.md) để biết việc được bắt đầu. Chưa cần skill riêng cho từng công cụ.
