## Target contract

- Staff-only request: `POST /api/v1/orders/:order_id/revisions/:revision/pdf-review-previews`.
- A successful response has schema `ai0.pdf_review_preview.v1`; it exposes the exact shop/order/revision/request/source/manifest digests and bounded preview page metadata, never private source or manifest bytes or storage locators.
- Preview PNG retrieval uses `GET /api/v1/orders/:order_id/revisions/:revision/previews/:index` with the staff bearer. Both responses must be `Cache-Control: no-store`.
- The Core raw `request_hash` and exact stored `request_data` must remain bound to the selected registered PDF `artifact_name`. Do not calculate a replacement hash over AI3-normalized settings or resolve a caller-supplied path.
- A preview is read-only: `ready=false`, `allowed_to_print=false`, `requires_staff_review=true`, `physical_print_verified=false`. It cannot confirm, approve, create a print job, send to a printer, or imply physical printing.
- The matrix is a future exact-candidate test plan. It does not claim this route is implemented or wired at the base SHA.
